# RetailPulse
AI-Powered Multi-Store Demand Forecasting and Inventory Optimization Platform.

## Features
- Retail demand forecasting
- Inventory risk detection
- Store-to-store inventory optimization
- Explainable recommendations
- Interactive analytics dashboard
- What-if simulation

## Tech Stack
- Python
- XGBoost
- FastAPI
- React
- PostgreSQL
- Google OR-Tools

## Dataset
Uses the publicly available M5 Forecasting dataset.
Raw dataset files are excluded from this repository.
